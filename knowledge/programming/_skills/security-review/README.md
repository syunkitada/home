# セキュリティレビュー

入力、認証・認可、秘密情報、外部サービス、依存関係などを含む変更を専門的に確認する skill です。実行入口は [SKILL.md](./SKILL.md) です。

## Index

| パス | 役割 |
| --- | --- |
| [SKILL.md](./SKILL.md) | 信頼境界、資産、攻撃経路、証拠、修正方針の確認手順 |

## 利用例

~~~text
$security-review この認証変更をセキュリティレビューしてください。認可漏れ、セッション、ログへの秘密情報露出を重点的に確認してください。
~~~

通常の差分レビューは `code-review`、実装は `implementation`、完了確認は `verification` を使います。
