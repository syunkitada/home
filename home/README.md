# homeディレクトリ用の設定ファイル郡

## Index

| Link | Description |
| --- | --- |
| [.config/](.config/) | zsh、tmux、Neovimなどの設定です。 |
| [.local/](.local/) | ユーザー固有のローカルツールです。 |
| [.envrc](.envrc) | 環境変数を設定するファイルです。 |
| [.zshrc](.zshrc) | zsh初期化時に読み込むスクリプトです。 |

## 各種ファイルの説明

| ファイル名 | 説明                                                                              |
| ---------- | --------------------------------------------------------------------------------- |
| [.envrc](.envrc) | 環境変数を設定するためのファイルです。 |
| [.zshrc](.zshrc) | zsh初期化時に最初に呼ばれるスクリプトです（`XDG_CONFIG_HOME/zsh/*.zsh`を読み込みます）。 |
