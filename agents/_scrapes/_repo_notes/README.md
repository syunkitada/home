# Programming Repository Notes

[`../_repos/`](../_repos/) に取得した外部レポジトリを、レポジトリごとに調査・要約した中間ノートです。ソースレポジトリのスナップショット、調査時点、主要な構成・機能・利用ワークフロー・検証方法を記録します。

`_repos/` は `mygit` が管理するローカル参照用キャッシュであり、ノートの内容は取得済みコミットに基づきます。最新状態や正確な仕様が必要な場合は、各ノートに記載したコミットとソースファイルを確認してください。
