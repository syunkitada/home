# 実装

仕様や要件に基づいて、コード、設定、ドキュメントを変更する skill です。構成変更に伴う README、目次やファイル一覧などの構成説明、相対リンクの同期も扱います。実行入口は [SKILL.md](./SKILL.md)、保守契約と設計根拠は [SPEC.md](./SPEC.md) です。

## Index

| パス | 役割 |
| --- | --- |
| [SKILL.md](./SKILL.md) | 実装前の調査、変更、テスト、完了報告の手順 |
| [SPEC.md](./SPEC.md) | 適用範囲、変更の契約、設計根拠、保守方針 |

## 利用例

~~~text
$implementation docs/spec.md の要件に従って実装してください。既存のテストを更新し、検証結果も報告してください。
~~~

コミットやPR作成は含めません。必要な場合は別途 `git-workflow` を使います。

## 維持・改善

`SKILL.md` の手順、境界、検証方針を変更した場合は [SPEC.md](./SPEC.md) とこの README の説明を同期します。外部資料や新しい内部方針を設計根拠として採用した場合は、参照箇所と採用内容を [SPEC.md](./SPEC.md) に追記します。
