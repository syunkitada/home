# コードレビューの参照資料

実行時に必要な手順を、レビューの分岐ごとに分けて管理します。外部リポジトリの取得状態に依存せず、このディレクトリだけで code-review スキルを利用できます。

## 目次

| [validation-playbook.md](./validation-playbook.md) | 指摘候補を再現・検証する手順と証拠の扱い |
