# Slack

対象は、依頼、報告、相談、決定事項、障害や進捗の共有、告知です。そのまま貼り付けられる短い文章を基本にします。

## 構成

1. 結論、依頼、状況のいずれかを最初に置く。
2. 判断や行動に必要な背景だけを続ける。
3. 必要なら、担当、期限、確認方法、次の行動を示す。
4. 返信してほしい内容がある場合は、質問を具体的にする。

情報が独立して並ぶ場合だけ箇条書きを使います。因果関係や経緯を箇条書きで切り刻み、読み手に関係を推測させないでください。

## 書き方

- チャンネルの既存の距離感に合わせ、不要な挨拶や定型的な前置きを省く。
- 依頼なら、対象、依頼内容、必要な期限または確認方法を明確にする。
- 報告なら、現在の状態、影響、対応、次の更新を分ける。
- 相談なら、決めたいことと、判断に必要な選択肢や背景を示す。
- メンション、担当者、期限、数値、障害原因は、素材にある場合だけ書く。
- 長い背景説明や手順は、Wikiや文書に分け、Slackには要点とリンクを置く。
- 絵文字、記号、強調は、チームの慣例や意味がある場合に限って使う。

Slack向けの文章を作るとき、本文の後に長い「改善ポイント」を付けず、必要な補足は依頼者へ確認する内容として分離します。
