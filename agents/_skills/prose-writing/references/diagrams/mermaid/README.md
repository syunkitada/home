## その他の図種

時間計画は `gantt`、ブランチの流れは `gitGraph` を使います。比率を示す `pie` や、利用者の体験を示す `journey` などもあります。ここにない図種は、公式資料で対象プラットフォームとバージョンへの対応を確認してから使います。
