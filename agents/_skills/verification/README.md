# 完了前検証

作業完了を主張する前に、要件と新しい実行結果を証拠に基づいて確認する skill です。実行入口は [SKILL.md](./SKILL.md)、保守契約と設計根拠は [SPEC.md](./SPEC.md) です。

## Index

| パス | 役割 |
| --- | --- |
| [SKILL.md](./SKILL.md) | テスト、静的検査、差分、未確認事項の検証手順 |
| [SPEC.md](./SPEC.md) | 適用範囲、証拠基準、報告契約、設計根拠、保守方針 |

## 利用例

~~~text
$verification この変更が完了したと言えるか、要件・テスト・差分を確認して報告してください。
~~~

検証だけの依頼では、失敗を隠すために実装を変更しません。確認できない項目は、理由、代替確認、残るリスクを分けて報告します。

## 維持・改善

`SKILL.md` の証拠基準、検証手順、対象範囲、報告形式を変更した場合は [SPEC.md](./SPEC.md) とこの README の説明を同期します。誤った完了主張、検証漏れ、過剰な全体テスト、未追跡ファイルの見逃しが見つかった場合は、発生条件と対応方針を [SPEC.md](./SPEC.md) に追記します。
