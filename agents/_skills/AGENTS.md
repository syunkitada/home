# Skill directory guidelines

このディレクトリ配下の各 skill は、次の役割分担で管理します。

## ファイルの役割

- `README.md` は利用者向けの入口とし、skill の目的、使い方、構成を説明する。
- `SKILL.md` は実行時の入口とし、実行手順、判断基準、利用する参照資料を記載する。
- 保守契約、設計根拠、参考資料、採用した調整内容は、原則として `SPEC.md` に記載する。

## 参考資料の管理

- 参考資料の出典、参照リビジョン、参照箇所、採用内容は `SPEC.md` にまとめる。
- `SOURCES.md` は原則として追加しない。出典情報が大量になった場合や、評価事例・設計判断と明確に分離する必要がある場合だけ、別ファイルへの分離を検討する。
- 参考リポジトリは、skill の実行時依存にしない。

## 構成変更

- ファイルやディレクトリを追加・削除・移動・改名した場合は、関係する README の構成説明、Index、相対リンクを同じ変更で更新する。
- README の Index には、Git 管理対象の直接の子ディレクトリとファイルだけを掲載し、生成物・ローカル専用ファイル・未追跡ファイルは掲載しない。
- `SKILL.md` の方針や保守契約を変更した場合は、必要に応じて `SPEC.md` と README の説明も同期する。
