# Git ワークフロー

ブランチ、作業ツリー、コミット、PR、競合解消などの Git 操作を安全に進める skill です。実行入口は [SKILL.md](./SKILL.md)、保守契約と設計根拠は [SPEC.md](./SPEC.md) です。

## 目次

| パス | 役割 |
| --- | --- |
| [SKILL.md](./SKILL.md) | Git の範囲確認、branch・worktree・履歴操作、外部操作、競合解消、破壊的操作の手順 |
| [SPEC.md](./SPEC.md) | 操作の適用範囲、確認基準、参考資料、リポジトリ向けの調整をまとめた保守契約 |

## 利用例

~~~text
$git-workflow この変更だけをコミットできる状態に整理し、staged diff と検証結果を確認してください。コミットはまだ作成しないでください。
~~~

push、PR、release など外部状態を変更する操作と、merge、tag などローカルの履歴や作業ツリーを変更する操作は、明示的に依頼された場合だけ行います。参考資料と設計上の調整は [SPEC.md](./SPEC.md) に記録しています。

## 維持・改善

`SKILL.md` の方針、参考資料のリビジョン、採用・不採用の判断を変更した場合は [SPEC.md](./SPEC.md) も同期します。実際の利用で誤操作、見逃し、過剰な確認が見つかった場合は、発生条件と検証結果をSPEC.mdへ追記して手順を調整します。
