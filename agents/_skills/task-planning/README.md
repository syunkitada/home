# タスク計画

要件を、依存関係とリスクを考慮した実装可能な計画、受け入れ条件、検証方法へ整理する skill です。実行入口は [SKILL.md](./SKILL.md)、保守契約と設計根拠は [SPEC.md](./SPEC.md) です。

## Index

| パス | 役割 |
| --- | --- |
| [SKILL.md](./SKILL.md) | 計画の発動条件、調査手順、出力内容 |
| [SPEC.md](./SPEC.md) | 適用範囲、計画の契約、設計根拠、保守方針 |

## 利用例

~~~text
$task-planning この機能追加の実装計画を作ってください。既存の利用箇所とテスト方針も含めてください。
~~~

計画だけの依頼ではプロダクトのコード、設定、テスト、コミットを変更しません。計画文書への保存を依頼された場合も、既存の未完了計画を確認してから扱います。実装、テスト、コミットは別の依頼として扱います。

## 維持・改善

`SKILL.md` の発動条件、計画手順、タスク形式、出力境界を変更した場合は [SPEC.md](./SPEC.md) とこの README の説明を同期します。外部資料や新しい内部方針を設計根拠として採用した場合は、参照箇所と採用内容を [SPEC.md](./SPEC.md) に追記します。
