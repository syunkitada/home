# テスト駆動開発

挙動変更やバグ修正を、失敗するテストから始めて実装する skill です。実行入口は [SKILL.md](./SKILL.md)、保守契約と設計根拠は [SPEC.md](./SPEC.md) です。

## Index

| パス | 役割 |
| --- | --- |
| [SKILL.md](./SKILL.md) | RED、GREEN、REFACTOR とテスト検証の手順 |
| [SPEC.md](./SPEC.md) | 適用範囲、TDDの契約、設計根拠、保守方針 |

## 利用例

~~~text
$tdd このバグを再現するテストを先に追加し、修正後に関連テストと全体テストを実行してください。
~~~

純粋な文書変更や挙動に影響しない静的設定の変更には適用しません。テストできない経路がある場合は、理由、代替検証、残るリスクを報告します。

## 維持・改善

`SKILL.md` の発動条件、RED・GREEN・REFACTORの手順、テスト方針を変更した場合は [SPEC.md](./SPEC.md) とこの README の説明を同期します。テストの誤検出、見逃し、環境依存、過剰なモックが見つかった場合は、発生条件と対応方針を [SPEC.md](./SPEC.md) に追記します。
