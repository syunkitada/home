# セキュリティレビュー

入力、認証・認可、秘密情報、外部サービス、依存関係などを含む変更を、脅威と証拠に基づいて専門的に確認する skill です。実行入口は [SKILL.md](./SKILL.md)、保守契約と設計根拠は [SPEC.md](./SPEC.md) です。

## Index

| パス | 役割 |
| --- | --- |
| [SKILL.md](./SKILL.md) | 信頼境界、資産、攻撃経路、証拠、修正方針の確認手順 |
| [SPEC.md](./SPEC.md) | 適用範囲、脅威モデル、証拠基準、報告契約、設計根拠、保守方針 |

## 利用例

~~~text
$security-review この認証変更をセキュリティレビューしてください。認可漏れ、セッション、ログへの秘密情報露出を重点的に確認してください。
~~~

通常の差分レビューは `code-review`、実装は `implementation`、完了確認は `verification` を使います。

## 維持・改善

`SKILL.md` の発動条件、脅威モデル、確認観点、証拠基準、報告形式を変更した場合は [SPEC.md](./SPEC.md) とこの README の説明を同期します。誤検出、見逃し、到達経路の調査不足、過剰なOWASP適用が見つかった場合は、発生条件と対応方針を [SPEC.md](./SPEC.md) に追記します。
