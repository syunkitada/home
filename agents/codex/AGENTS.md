# Codex 設定のレビュー前提

このディレクトリのCodex設定は、ホストOS上で直接実行することを前提にした一般用途の設定ではありません。隔離された開発用VM内でCodexを実行することを前提に管理します。

## 意図している設定

- `config.toml` の `sandbox_mode = "danger-full-access"`
- 開発用プロジェクトに対する `trust_level = "trusted"`
- `rules/my.rules` にある、開発ツールやスクリプト実行系コマンドの許可

これらはVMを外側のセキュリティ境界とするための意図した設定です。通常の再レビューでは、ホストOS上で直接実行する場合の一般的な危険性として、これらを指摘しません。

ただし、次の場合は再評価します。

- CodexをVMの外で実行する運用に変わった
- VMからホストのファイルシステム、認証情報、本番環境へアクセスできるようになった
- 許可範囲や対象プロジェクトが開発環境の範囲を越えた
- VMによる隔離が実際には機能していないことが分かった
