# Codex: config

## sandbox_mode と approval_policy について

sandboxは、「そもそも何が実行可能か」を決める。

approvalは、「実行可能な操作でも、ユーザーに確認するか」を決める。

という関係です。

```
                sandbox_mode
                     │
          ┌──────────┴──────────┐
          │                     │
       許可される             許可されない
       操作                    操作
          │
          ▼
    approval_policy
          │
     ┌────┴────┐
     │         │
   自動実行   承認要求
```

### sandbox_mode の種類

| 項目                | `read-only` | `workspace-write` | `danger-full-access` |
| ----------------- | ----------- | ----------------- | -------------------- |
| ファイル読み取り          | 可           | 可                 | 可                    |
| ファイル作成・編集         | 不可          | 可                 | 可                    |
| workspace内の変更     | 不可          | 可                 | 可                    |
| workspace外のファイル変更 | 不可          | 不可                | 可                    |
| ネットワーク            | 制限あり        | 制限あり              | 可                    |
| システムへの影響          | 小           | 中                 | 大                    |
| 安全性               | 高           | 高め                | 低め                   |
| 主な用途              | コードレビュー・調査  | 通常の開発             | 強い権限が必要な作業           |

### approval_policy の種類

| 項目                    | `on-request` | `never` |
| --------------------- | ------------ | ------- |
| 承認確認                  | 必要に応じて表示     | 表示しない   |
| ユーザーの介入               | あり           | なし      |
| 自律性                   | 中            | 高       |
| sandboxの制限            | 受ける          | 受ける     |
| `workspace-write`との相性 | 良い           | 良い      |
| 対話型開発                 | 適している        | やや不向き   |
| 自動化・CI                | やや不向き        | 適している   |
| 安全性                   | 高め           | 注意が必要   |
